# internal/ — 講師・作成者用（受講者非公開）

このディレクトリと `.claude/agents/` には**演習の答え（隠し仕様・罠の一覧）**が含まれます。
`.claude/settings.json` の `permissions.deny` で、Claude からの読み取りを拒否しています。

## 中身

| ファイル | 用途 |
|---|---|
| `テスト実行ログ_review-feature_標準.md` | 標準難度の通し実行ログ＋メタ評価＋作成者の方針決定（§13, §14） |
| `レビュー資料.html` | カリキュラムのレビュー用資料 |

## 作成者向けメモ

- **エージェント定義（`.claude/agents/spec-sparring-client.md`）を編集するとき**は、
  `.claude/settings.json` の `deny` を一時的に空にしてください。
  deny 対象のファイルは Claude から編集もできません（Edit は Read を前提とするため）。
  編集が終わったら deny を元に戻すこと。
- **隠し仕様をエージェント定義の外に出さないこと。** 別ファイル（`cases/*.yaml` 等）にすると、
  顧客役エージェント自身が Read で読む必要が生じ、deny と両立しません。
  エージェント定義はシステムが自動で読み込むため、Read 権限が不要で、deny と共存できます。
- **受講者に配布するとき**は、このディレクトリを外すか、別ブランチ／別リポジトリに分けてください。
  現状 git 管理下にあるため、clone するとそのまま付いてきます。
