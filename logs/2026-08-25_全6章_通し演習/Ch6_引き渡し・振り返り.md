## 1. 返却APIの所有者照合

`/Users/r-mori/Desktop/aidd-curriculum/ch4-app/app/api/lendings/[id]/return/route.ts`

`updateMany` の where に所有者照合と `returnedAt: null` を畳み込みました。SELECT してから分岐しない形です。

```ts
const updated = await prisma.lending.updateMany({
  where: {
    id: params.id,
    returnedAt: null,
    ...(isAdmin ? {} : { userId: session.userId }),
  },
  data: { returnedAt: new Date(), returnedById: session.userId },
});
```
