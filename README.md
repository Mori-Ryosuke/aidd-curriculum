# AIDD 要件定義 壁打ち演習キット

曖昧な要望を、AIを使って実装可能な仕様（AC付きユーザーストーリー）まで詰める練習キットです。
相手役のAIエージェント `spec-sparring-client` が「曖昧な顧客」として出題し、あなたの提出仕様を採点します。

## 中身

```
aidd-curriculum/
├── README.md                         ← いま読んでいるファイル
├── 受講者ガイド.md                    ← 使い方・提出フォーマット・模範解答（まず読む）
├── 手法をAIで回すプロンプト集.md        ← INVEST/MoSCoW等をAIに実行させる雛形
├── .claude/
│   ├── settings.json                 ← 答えのファイルをAIに読ませないための設定
│   └── agents/
│       └── spec-sparring-client.md   ← 壁打ちエージェント本体（★答えが書いてある。開かない）
└── internal/                         ← 講師・作成者用の内部資料（★答えが書いてある。開かない）
```

## 準備（初回だけ）

1. このフォルダ（`aidd-curriculum`）を Claude Code で開く
   - ターミナルなら：`cd ~/Desktop/aidd-curriculum && claude`
2. エージェントが使えるか、こう打って確認：
   ```
   spec-sparring-client で出題して。題材は review-feature。難易度は標準。
   ```
   → 曖昧な要望が返ってくればOK。

## 演習の進め方

```
① 出題        顧客（田中さん）が曖昧な要望を出す
② 逆質問       顧客に質問して目的・条件を引き出す（顧客は聞かれた分だけ答える）
③ 手法で詰める  自分のAIにINVEST/MoSCoW等を実行させて仕様に落とす（プロンプト集参照）
④ 提出        できあがった仕様を「評価して」と提出
⑤ 採点・再挑戦  隠れた論点をいくつ掘れたか採点。漏れを埋めて再挑戦
```

- 出題：`spec-sparring-client で出題して。題材は review-feature。難易度は標準。`
- 逆質問：出題のあと、そのまま質問を書けば Claude が顧客役に取り次ぎます
  （例：「未購入者も書ける想定ですか？」）
- 提出：`spec-sparring-client で評価して。題材 review-feature。提出仕様は以下：（フォーマットに沿って貼る）`

くわしい手順・提出フォーマット・模範解答は **`受講者ガイド.md`**、
手法のAIでの回し方は **`手法をAIで回すプロンプト集.md`** を見てください。

> ポイント：手法（INVEST/MoSCoW等）は暗記していなくてもOK。**AIに実行させて、あなたが判断・修正する**——
> これがAIDDの要件定義の進め方で、この演習で身につける力です。

## 難易度

| 難易度 | ヒント |
|---|---|
| 易 | 隠れた論点の個数＋観点を教えてくれる |
| 標準 | 観点だけ軽く示す（おすすめ） |
| 難 | ヒントなし |

`難易度は易。` のように指定できます。

## 注意

- **`.claude/agents/` と `internal/` は開かないでください。** 演習の「答え（隠し仕様・罠の一覧）」が
  書かれています。先に見てしまうと練習になりません。
- **AIにも読ませないでください。** あなたが開かなくても、Claude が親切心でファイルを読みに行くことがあります。
  `.claude/settings.json` でこの2箇所の読み取りを拒否済みですが、念のため**演習を始める前に、最初の一言として
  次を伝えてください**：
  ```
  これから要件定義の演習をします。.claude/agents/ と internal/ は絶対に読まないでください。
  それから、私が聞いていない論点を先回りして教えないでください。掘るのは私の役割です。
  ```
  ※ 2文目が重要です。Claude が「次はこれを聞くといいですよ」と先回りすると、演習になりません。
- 「答えを教えて」とエージェントに聞いても教えてくれません（そういう設計です）。
- 顧客役は実在の担当者のように話します。「いい感じで」「よくあるやつ」を鵜呑みにせず、自分から掘ってください。
- 顧客は**一度は粘ります**。正しい指摘でも一発では折れないので、根拠を2つ用意して押してください。
